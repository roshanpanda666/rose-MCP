              Menu wheel

              The quick-action dial floating on the desktop: apps, Brave tabs, laptop toggles, window controls, power.

              Keyboard
              
            
              While the wheel is open, typing drives the outermost ring.
              
            
                
              
              • a l w p on the main ring: open Apps, Laptop, Windows, Power (other letters pick that menu)
                • 
              
              • Letters in a ring: jump to the match (apps: dock favorites first, then the ones you launch most)
                • 
              
              • Enter: run the focused item (an app launches and the wheel closes)
                • 
              
              • ← →: turn the ring one item
                • 
              
              • Backspace: delete a letter; with none typed, back one ring
                • 
              
              • Esc: clear, then back one ring, then close
                • 
              
              • Mouse: click an item to run it; drag or scroll to turn; drag the round button to move the wheel
                •
